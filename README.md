# ТЭК — интернет-магазин электротехники (Точикэлектрокомплект)

Маркетплейс + корпоративный сайт по ТЗ «Сайт ТЭК.docx» и макету Figma.

| Слой      | Стек                                                     | Порт (dev) |
|-----------|----------------------------------------------------------|-----------|
| Backend   | Rust · Axum 0.8 · Tokio · SQLx 0.9 · PostgreSQL 18 · moka | 8181      |
| Frontend  | Bun · Next.js 16 (App Router) · React 19 · Tailwind 4     | 3010      |
| DB        | PostgreSQL 18 (docker compose)                            | 5433      |

## Быстрый старт

```bash
# 1. База
docker compose up -d postgres

# 2. Бэкенд (миграции и сид данных выполняются автоматически)
cd backend && cp .env.example .env && cargo run --release

# 3. Фронтенд
cd frontend && cp .env.example .env.local && bun install && bun run dev -p 3010
```

Или всё сразу: `./scripts/dev.sh`.

Открыть: http://127.0.0.1:3010 · API: http://127.0.0.1:8181/api/v1/health

Проверка: `./scripts/e2e.sh` (статусы всех страниц и эндпоинтов + скриншоты в `/tmp/tek-e2e`), `backend/scripts/smoke.sh` (89 проверок API), `cd frontend && bun run lint && bun run build`.

Производительность (oha, 64 соединения, release-сборка, локально): листинг каталога ~30 000 rps (p99 14 мс), карточка товара ~47 000 rps (p99 3 мс), главная ~17 000 rps.

## Что реализовано из ТЗ

* Ценообразование: прайс для гостей, персональная скидка/кешбэк по аккаунту с правилами по товару/бренду/категории.
* Карточка товара: динамические торговые предложения (SKU-группы), характеристики, кратность упаковки, распродажа, остатки по магазинам, комплектующие, документация (общие документы), конфигуратор, бренд/страны, отзывы и вопросы.
* Корзина: смета в Excel, поделиться корзиной (цены под аккаунт получателя), купоны, скидки по позициям, проверка остатков, доставка в чекауте, оплата Алиф/ДС (заглушка модуля) и по счёту для B2B, резерв в 1С и отправка в CRM через outbox, маршрутизация заказа менеджеру/лид-менеджеру.
* Личный кабинет: одобрение регистрации, личные/компания, акт сверки за период (+Excel), история заказов (30 дней по умолчанию, отмена/редактирование недоставленных, событие в CRM), бонусная карта с детализацией, отзывы/вопросы с уведомлениями об ответах.
* Корпоративный сайт: структура как у tectj.com (О компании, Услуги, Проекты, Поддержка, Контакты, Помощь) + конфигураторы.
