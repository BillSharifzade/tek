# ТЭК — интернет-магазин электротехники (Точикэлектрокомплект)

Маркетплейс + корпоративный сайт по ТЗ «Сайт ТЭК.docx» и макету Figma.

| Слой      | Стек                                                     | Порт (dev) |
|-----------|----------------------------------------------------------|-----------|
| Backend   | Rust · Axum 0.8 · Tokio · SQLx 0.9 · PostgreSQL 18 · moka | 8181      |
| Frontend  | Bun · Next.js 16 (App Router) · React 19 · Tailwind 4     | 3010      |
| DB        | PostgreSQL 18 (docker compose)                            | 5433      |

## Быстрый старт

```bash
# 1. База
docker compose up -d postgres

# 2. Бэкенд (миграции и сид данных выполняются автоматически)
cd backend && cp .env.example .env && cargo run --release

# 3. Фронтенд
cd frontend && cp .env.example .env.local && bun install && bun run dev -p 3010
```

Или всё сразу: `./scripts/dev.sh`.

Открыть: http://127.0.0.1:3010 · API: http://127.0.0.1:8181/api/v1/health

Проверка: `./scripts/e2e.sh` (статусы всех страниц и эндпоинтов + скриншоты в `/tmp/tek-e2e`), `backend/scripts/smoke.sh` (89 проверок API), `cd frontend && bun run lint && bun run build`.

Производительность (oha, 64 соединения, release-сборка, локально): листинг каталога ~30 000 rps (p99 14 мс), карточка товара ~47 000 rps (p99 3 мс), главная ~17 000 rps.

## Что реализовано из ТЗ

* Ценообразование: прайс для гостей, персональная скидка/кешбэк по аккаунту с правилами по товару/бренду/категории.
* Карточка товара: динамические торговые предложения как у Петровича — группа исполнений с несколькими осями (например «Число полюсов × Номинальный ток»), у каждого исполнения свой URL, код, цена, фото и остатки; переключение без перезагрузки, недоступные сочетания ведут к ближайшему исполнению (схема: `product_groups.axes` + `products.variant`, миграция 0003; семейства сида собирает `seed::group_variants`, иллюстрации исполнений рисует `frontend/src/app/art`). Характеристики, кратность упаковки, распродажа, остатки по магазинам, комплектующие, документация (общие документы), конфигуратор, бренд/страны, отзывы и вопросы.
* Корзина: смета в Excel, поделиться корзиной (цены под аккаунт получателя), купоны, скидки по позициям, проверка остатков, доставка в чекауте, оплата Алиф/ДС (заглушка модуля) и по счёту для B2B, резерв в 1С и отправка в CRM через outbox, маршрутизация заказа менеджеру/лид-менеджеру.
* Личный кабинет: одобрение регистрации, личные/компания, акт сверки за период (+Excel), история заказов (30 дней по умолчанию, отмена/редактирование недоставленных, событие в CRM), бонусная карта с детализацией, отзывы/вопросы с уведомлениями об ответах.
* Корпоративный сайт: структура как у tectj.com (О компании, Услуги, Проекты, Поддержка, Контакты, Помощь) + конфигураторы.
* Заявки со всех форм сайта (услуги, обратная связь, «не нашли ответ») — `POST /leads` → таблица `leads` + событие `lead.created` в CRM через outbox.
* Проекты: бренды, продукция каталога, фото с объекта, видео; фильтры «Вендоры» / «Продукция». Новости с тегами.

## Продакшн

```bash
cp .env.production.example .env        # заполнить: SITE_URL, PUBLIC_ORIGIN, POSTGRES_PASSWORD, JWT_SECRET, ADMIN_*…
docker compose -f docker-compose.prod.yml up -d --build
# за общим reverse proxy другого проекта (одна docker-сеть):
docker compose -f docker-compose.prod.yml -f deploy/edge-network.override.yml up -d
```

* `APP_ENV=production`: бэкенд не стартует с небезопасными настройками (дефолтный JWT_SECRET, CORS `*`, не-https FRONTEND_URL,
  демо-аккаунты без `DEMO_STAND=true`). Первый администратор — из `ADMIN_EMAIL` / `ADMIN_PASSWORD`.
* Наружу публикуются только `127.0.0.1:18181` (API) и `127.0.0.1:13010` (сайт) — TLS и маршруты на reverse proxy
  (пример для подпути `/tek` — `deploy/Caddyfile.tek`; сайт в подпути собирается с `BASE_PATH=/tek`).
* База — только во внутренней сети; ежедневный `pg_dump` в том `tek-backups` (14 последних).
* Онлайн-оплата Алиф / ДС выключена до подключения эквайринга (callback без подписи в production отключён).
  События в CRM / 1С копятся в очереди, пока не заданы `CRM_WEBHOOK_URL` / `ONEC_WEBHOOK_URL`.
* Сброс пароля (писем пока нет): `docker compose exec -e NEW_PASSWORD='…' tek-api /app/tek-api set-password user@example.com`.
