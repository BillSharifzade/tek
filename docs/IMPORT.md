# Импорт каталога (Excel / CSV)

Основной способ загрузить и обновлять реальный каталог: выгрузка номенклатуры из 1С в Excel → загрузка в панели управления
(раздел «Импорт», только администратор) или из консоли сервера. Товар ищется по **коду**: нового кода в базе нет — товар
создаётся, код уже есть — обновляются только заполненные ячейки. Поэтому один и тот же формат подходит и для первичной
загрузки, и для ежедневного обновления цен и остатков.

* Панель: `POST /api/v1/admin/import/catalog` (multipart, поле `file`), «Только проверить» — `?dry_run=1`.
* Шаблон с текущими складами и строкой-примером: `GET /api/v1/admin/import/template.xlsx` (кнопка «Скачать шаблон»).
* Консоль сервера: `tek-api import catalog.xlsx --dry-run`, затем `tek-api import catalog.xlsx` (отчёт — JSON в stdout).
  В docker (production): файл скопировать в контейнер и запустить бинарник `/app/tek-api`:
  ```bash
  docker compose -f docker-compose.prod.yml cp catalog.xlsx tek-api:/tmp/catalog.xlsx
  docker compose -f docker-compose.prod.yml exec tek-api /app/tek-api import /tmp/catalog.xlsx --dry-run
  docker compose -f docker-compose.prod.yml exec tek-api /app/tek-api import /tmp/catalog.xlsx
  ```

## Файл

* `.xlsx` (также `.xls`, `.ods`) — читается первый лист (лист «Инструкция» из шаблона пропускается);
  `.csv` — UTF-8 (с BOM или без) или Windows-1251, разделитель `;`, `,` или табуляция (определяется по строке заголовков).
* До **20 МБ** и **100 000** строк за раз (больше — разделите файл).
* Первая непустая строка — **заголовки**, дальше — по товару в строке. Регистр и лишние пробелы в заголовках не важны,
  `ё` = `е`. Незнакомые столбцы пропускаются и перечисляются в отчёте (`ignored_columns`). Пустые строки пропускаются.

## Столбцы

| Заголовок | Обязателен | Что означает |
|---|---|---|
| `Код` | всегда | Код номенклатуры из 1С — ключ товара (до 64 символов). Синонимы: «Код товара», «Код номенклатуры». В Excel держите столбец текстовым, чтобы не терялись ведущие нули (в шаблоне так и сделано). |
| `Наименование` | для нового | Название товара (до 300 символов). Адрес страницы (`/product/<slug>`) создаётся из названия один раз и при переименовании не меняется. |
| `Категория` | для нового | Путь раздела через ` / `: `Кабели и провода / Силовые кабели`. Существующие разделы находятся по названию (или slug) на каждом уровне, недостающие создаются (slug — транслитерацией, как у существующих: `kabelenesushchie-sistemy`). Можно указать одно название, если раздел с таким названием в каталоге один — иначе ошибка строки «укажите путь». Синонимы: «Раздел», «Группа». |
| `Бренд` | нет | Название (или slug) бренда; нового бренда нет — создаётся. Синоним: «Производитель». |
| `Ед. изм.` | нет | `шт` (по умолчанию) или `м` — метры можно заказывать дробным количеством. «шт.», «штука», «метр», «м.п.» приводятся сами; другие короткие единицы («компл», «упак») сохраняются как есть. |
| `Цена` | для нового | Прайсовая цена, с.: `1 690,80`, `1690.80`, `1 690,80 с.` — больше нуля. |
| `Цена распродажи` | нет | Цена со скидкой — ниже прайсовой (с учётом новой или текущей цены товара). Пусто — не менять; `0` или `-` — снять распродажу. |
| `Кратность` | нет | Шаг количества в корзине: кабель в бухте 100 м — `100`, лоток 3 м — `3`. `0` или `-` — убрать кратность. |
| `Описание` | нет | Текст описания товара. |
| `Изображение` | нет | Ссылка `https://…` или путь `/…`; несколько — через `;`. Заменяет все фото товара. |
| `Остаток <склад>` | нет | Столбец на каждый склад: `Остаток dushanbe` (код склада) или `Остаток Центральный склад` (название). Значение — остаток, доступный к продаже (заказы сайта уже списаны); отрицательный считается нулём. Пусто — не менять. Неизвестный склад в заголовке — ошибка всего файла (список складов — в сообщении и в шаблоне). Если склад один, можно просто `Остаток`. |
| `Хар: <название>` | нет | Характеристика товара, например `Хар: Сечение, мм²` или `Хар: Степень защиты`. Значение заменяет одноимённую характеристику, новая добавляется, `-` удаляет. Характеристики становятся фильтрами раздела каталога. |

Новый товар: обязательны `Наименование`, `Категория`, `Цена`; остальное — по желанию. Новые товары создаются в продаже,
без бейджей «Хит» / «Новинка» (их и снятие с продажи меняют в панели: «Товары»).

Существующий товар: меняются только непустые ячейки. Строка, где кроме кода ничего не заполнено, пропускается без ошибки.

## Примеры

Первичная загрузка (`;`-CSV, то же самое в Excel):

```
Код;Наименование;Категория;Бренд;Ед. изм.;Цена;Цена распродажи;Кратность;Остаток dushanbe;Остаток khujand;Хар: Сечение, мм²
100001;Кабель ВВГнг(А)-LS 3х2,5;Кабели и провода / Силовые кабели;Кавказкабель;м;12,50;;100;5000;1200;2,5
100002;Автоматический выключатель ВА47-29 1P 16А;Низковольтное оборудование / Модульные автоматы;IEK;шт;45;39,90;;320;40;
```

Обновление только цен:

```
Код;Цена;Цена распродажи
100001;13,20;
100002;47;-
```

Обновление только остатков (ежедневная выгрузка из 1С):

```
Код;Остаток dushanbe;Остаток khujand;Остаток kushoniyon
100001;4800;1150;0
100002;310;38;12
```

## Как проходит импорт

1. Проверяются заголовки: нет `Код`, неизвестный склад или столбец указан дважды → ответ 422 `invalid_header`, ничего не записывается.
2. Весь файл обрабатывается в **одной транзакции**. Строка с ошибкой (не число в цене, распродажа выше цены, у нового товара
   не хватает обязательных полей, неоднозначная категория…) пропускается и попадает в отчёт с номером строки файла
   (заголовок — строка 1); остальные строки записываются.
3. После записи пересчитываются счётчики товаров в разделах, сбрасывается кэш витрины (из консоли — витрина обновится
   в течение минуты). В CRM / 1С импорт ничего не отправляет.
4. «Только проверить» (`dry_run=1`, `--dry-run`) делает всё то же самое, но откатывает транзакцию — отчёт показывает, что
   произойдёт, ничего не меняя.

Отчёт:

```json
{
  "dry_run": false, "rows": 1250, "created": 300, "updated": 940, "skipped": 10,
  "categories_created": 4, "brands_created": 2, "stock_rows": 3700,
  "errors": [{ "row": 17, "message": "Цена: «12,5,0» — не число" }],
  "ignored_columns": ["Комментарий"]
}
```

`skipped` — строки с ошибками и строки без изменений; `errors` — до 1000 первых ошибок; `stock_rows` — записано значений
остатков (товар × склад).

## Советы по выгрузке из 1С

* «Номенклатура» → список → «Ещё → Вывести список…» → отметить нужные колонки → сохранить как Excel (.xlsx); заголовки
  переименовать как в таблице выше (или выгрузить в шаблон из панели).
* Иерархию групп номенклатуры удобно собрать в одну колонку «Категория» формулой: `=A2&" / "&B2`.
* Для ежедневного обновления достаточно колонок `Код` и `Остаток …` (и `Цена`, если меняются цены).
* Перед первой большой загрузкой запускайте «Только проверить».
